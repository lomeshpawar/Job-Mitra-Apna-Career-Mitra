⌕

Job discovery

♙

Candidate workspace

Manage candidate profiles, skills, applications, and application status tracking.

Run the full application locally

1. Install dependencies

Use Python and install the packages listed in requirements.txt.

2. Configure safely

Copy .env.example to .env and set a strong local secret key. Never commit real credentials.

3. Start Flask

Run python app.py from the project root and open http://127.0.0.1:5000.
